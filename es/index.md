# Security Analysis Suite — Portfolio de Guillermo R.S.

Bienvenido a mi portfolio de ciberseguridad.  
Este sitio documenta mi **Plan Acelerado de 8 Semanas para la Transición a Ciberseguridad**, un proyecto estructurado e intensivo diseñado para demostrar habilidades reales de seguridad defensiva mediante módulos prácticos completamente documentados.

Cada semana del plan incluye:

- objetivos claros  
- tareas técnicas  
- entregables profesionales  
- documentación completa  
- repositorios asociados  
- progreso real de aprendizaje  

Durante la Semana 2 también introduje un módulo adicional: **CVE‑Hunter**, una herramienta propia para correlación de CVEs y análisis de vulnerabilidades.

## El Plan Acelerado de 8 Semanas

### Semana 1 — Instalación y Auditoría de Red
- Instalación de **Ubuntu 26.04 LTS**  
- Configuración de BIOS (Secure Boot, AHCI)  
- Instalación de herramientas base  
- Auditoría completa con Nmap  
- Script Bash de auditoría  
- Informe profesional de red  
- **Módulo adicional:** análisis WRT54G

### Semana 2 — Vulnerabilidades y CVEs
- Instalación y configuración de OpenVAS  
- Escaneo de dispositivos de la red doméstica  
- Correlación de CVEs (NVD, CVE Details, ExploitDB)  
- Clasificación de vulnerabilidades por impacto  
- Informe profesional de vulnerabilidades  
- **Módulo adicional:** CVE‑Hunter

### Semana 3 — Hardening de Sistemas
- Hardening de Ubuntu con Lynis  
- Hardening de Windows 11  
- Checklist profesional de seguridad  
- **Inicio de la construcción del portfolio (GitHub + GitHub Pages)**

### Semana 4 — Laboratorio Profesional
- Creación de máquinas virtuales (Kali, Ubuntu Server, Windows 11)  
- Instalación de Metasploitable y OWASP Juice Shop  
- Configuración de red interna  
- Documentación completa del laboratorio

### Semana 5 — Scripting de Seguridad
- Scripts Bash para escaneos y análisis de puertos  
- Scripts Python para CVEs, logs y tráfico  
- Documentación técnica de cada script

### Semana 6 — SOC y Análisis de Logs
- Análisis de syslog, auth.log, firewall, DNS  
- Detección de anomalías  
- Simulación de incidente  
- Informe SOC completo

### Semana 7 — DevSecOps Básico
- Pipeline con SAST + DAST  
- Escaneo de dependencias  
- Escaneo de contenedores  
- Documentación del pipeline

### Semana 8 — Portfolio y Aplicación a Empresas
- **Completar portfolio técnico (GitHub + GitHub Pages)**  
- CV adaptado a roles de seguridad  
- Aplicación a empresas  
- Preparación de entrevistas técnicas
